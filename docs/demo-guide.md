# 实时检测与人群分析演示

打开 `http://JETSON_IP:8090`（使用你的设备地址）。左侧默认自动播放实际视频并逐帧检测，短片结束后循环。页面标注“视频实时检测 · LIVE”与循环轮次；暂停、定位和 ROI 编辑仍可操作。右侧的回放及报告抽屉不接管左侧画面。

## 中英文切换

页头选择中文 / English；界面立即切换并记住选择。下一轮演示和新会话的分析使用所选语言生成。历史报告保留原文；界面语言与原文不同时会标注原始语言。切换语言不打断已有视频或分析。

## 分别录制 OFF / ON

主屏按当前浏览器可用高度布置，桌面保持左视频、右分析；1920×1080、1440×900、1366×768、1280×720 均可同屏展示主要内容。工具栏的“全屏”可进一步扩大录制画面，无需缩放网页。

1. 选择 **MTP OFF**，准备好自己的录屏工具，点击 **开始本轮演示**。视频从头实时检测，达到阈值后生成本轮分析，完成后可停止自己的录制。
2. 选择 **MTP ON**，再次点击 **开始本轮演示**，按同样流程录制另一段。
3. 每轮保留相同 ROI、阈值、持续与恢复规则，启用事件检测和自动处置，使用 1× 速度；会话、事件和报告重新生成。正在执行或实验时不允许重开，若有外部模型实例会显示原因。
4. 大号 OFF / ON 标记对应右侧正在显示的模式，任务计时使用本次真实流式记录和最终服务端结果；模型加载准备单列说明，不冒充任务时间。末行 Token / Decode 来自服务端。
5. 两次录制是独立检测事件。严谨性能对比使用“历史对照”中同一冻结输入的配对实验，不能将这两段独立演示当作输入完全相同的基准。

## 看真实异常分析

当前人数达到 5 人并持续 1.5 秒时，保存事件抓拍和检测依据，然后由本地 LLM 执行告警、通知并分析人群情况。右侧显示事件触发时间，报告讲的是该触发时刻，不把它伪装成稍后视频画面的即时结论。

主屏右侧只显示本轮所选模式的分析，先展示异常判断，再展示停留与移动分析、处置建议。可点击“完整报告”查看和下载。左侧视频继续检测，右侧按真实输出和工具回执点亮步骤。

一次实际事件的依据为：触发时 6 人达到 5 人阈值，连续超限 1.52 秒；5 人位移明显、1 人位移较小，最长连续可见 1.52 秒。LLM 据此给出人数超限结论，同时说明短时观察不足以确认长期滞留或通行堵塞。人数降至 3 人及以下并持续 2 秒，满足的是人数告警恢复条件，现场仍需核实。

移动分类来自检测框底部中心点在最近 3 秒内的画面归一化位移；连续观察不足 0.8 秒的目标归为“观察不足”。这不是物理速度或动作识别，位移小不直接等于站立不动。模型不判断身份、意图，不虚构打斗、跌倒或现场安全结论。

自动循环同一短片继续进行真实推理，复用该片段已有事件，不重复堆积分析任务。手动重播、定位或配置变更开启新会话，可产生新的真实事件。

## 看 MTP 处理过程差别

打开“历史对照”，选择配对组并点击“播放处理过程”。两条路径按原始 Trace 时间推进，报告只展示该时刻实际已生成的内容，持续显示 `Recorded Run Replay`。左侧视频仍独立实时检测；右侧的事件时间和人数明确标出，不能把两者当作同一时刻。

OFF / ON 实验在同一设备上顺序运行，每种模式预热、使用相同事件与请求。完整任务、Decode、加载和首 Token 指标分别记录，页面只显示所选实验的实际结果。新版分析 Prompt 有独立实验目录，不混用此前技术报告的性能数字。

只有主动运行独占性能实验时，视频检测计算暂缓，页面显示原因；结束后恢复播放。普通 LLM 分析和记录回放均不暂停检测。

## 配置和证据

- 设置：阈值、持续时间、恢复、冷却、模式、循环开关、ROI、加载视频、全部检测框、人数 CSV。
- 事件记录：原始抓拍、工具回执、提醒确认、报告、重试及取消。
- 历史对照 → 查看统计与原始记录：历史实验、各轮成功/失败/取消、详细指标、重新实测、ZIP 导出。

检测处理全部源帧，预览图像最多约 10 次/秒发送，以保障远程状态和报告刷新。每张预览的图像、检测框、人数与时间戳来自同一帧；没有插补或伪造检测帧。状态接口采用压缩传输，前端避免重叠轮询。
